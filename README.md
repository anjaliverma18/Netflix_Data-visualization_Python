# 🎬 Netflix Dataset Visualization  

## 📌 Project Overview  
This project focuses on exploring and visualizing a Netflix dataset using Python. It uses data analysis and visualization libraries to understand the dataset's structure, explore content-related attributes, and identify patterns that can be investigated through visualizations.  

## 🎯 Objectives  
- Load and explore the Netflix dataset using Pandas.  
- Understand the dataset's structure, columns, and data types.  
- Examine IMDb ratings, Hidden Gem Scores, and scores.  
- Explore information about directors, writers, actors, runtime, and country availability.  
- Create visualizations to communicate insights from the dataset.  

## 🛠️ Technologies Used  
- **Python** — Programming language  
- **Pandas** — Data manipulation and analysis  
- **Matplotlib** — Data visualization  
- **Seaborn** — Statistical data visualization  
- **Jupyter Notebook** — Interactive development environment  

## 📂 Dataset Information  
The dataset is provided as a CSV file and is loaded directly into the notebook.  

**Dataset URL:**  
https://itv-contentbucket.s3.ap-south-1.amazonaws.com/Exams/AWP/pandas/Netflix.csv  

The dataset contains information about Netflix titles, including:  

| Column | Description |  
| Title | Name of the movie or series |  
| Genre | Genre or genres associated with the title |  
| Languages | Languages associated with the content |  
| Series or Movie | Indicates the type of content |  
| Hidden Gem Score | Hidden Gem Score recorded in the dataset |  
| Country Availability | Country where the title is available |  
| Runtime | Runtime information |  
| Director | Director of the title |  
| Writer | Writer of the title |  
| Actors | Actors associated with the title |  
| View Rating | Content rating |  
| IMDb Score | IMDb rating recorded in the dataset |  
| Rotten Tomatoes Score | Rotten Tomatoes score recorded in the dataset |  


## ⚙️ Project Workflow  
1. Import the required Python libraries.  
2. Load the Netflix CSV dataset using Pandas.  
3. Inspect the dataset using methods such as `head()`, `shape`, `info()`, and `describe()`.  
4. Check for missing values and duplicate records.  
5. Clean and prepare the data where necessary.  
6. Perform exploratory data analysis (EDA).  
7. Create suitable charts using Matplotlib and Seaborn.  
8. Interpret the results and summarize the insights.  

## 📊 Possible Analysis and Visualizations  
- Distribution of movies and series.  
- Distribution of IMDb ratings across countries.  
- Comparison of IMDb scores of movies and series.  
- Runtime distribution & average box-office collection.      
- Top Directors by number of films.  

## 🚀 How to Run the Project  

### Prerequisites  
Install Python and Jupyter Notebook, or use an environment that supports Jupyter notebooks.  

### Step 1: Clone the repository  
```bash  
git clone https://github.com/YOUR-USERNAME/netflix-dataset-visualization.git  
```  

### Step 2: Navigate to the project folder  
cd netflix-dataset-visualization    

### Step 3: Install the required libraries  
pip install pandas matplotlib seaborn jupyter    
 
### Step 4: Launch Jupyter Notebook  
jupyter notebook  

### Step 5: Run the notebook  
Open the project notebook and execute the cells sequentially.
